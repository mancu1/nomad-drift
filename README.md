# Nomad Drift — генератор следующей страны

Статическое веб-приложение: путешествие цепочкой стран, куда с паспортом РФ
пускают без визы (или с визой по прилёту / электронной), в сторону целевой страны.
Каждый шаг — взвешенный случайный выбор среди стран в смещённой к цели окружности.

Vite + React + TypeScript, d3-geo + TopoJSON. Без бэкенда, состояние в `localStorage`.

## Команды

```bash
npm install
npm run dev          # локальная разработка
npm test             # unit-тесты, симуляция, проверка Атлантики
npm run sim          # отчёт симуляции (по умолчанию Турция → Уругвай, 1000 прогонов)
npm run sim -- GE BR 500 42   # старт, цель, прогонов, seed
npm run build        # сборка в dist/
npm run data:report  # сколько стран в каждом режиме и сколько не подтверждено
npm run data:build   # пересобрать data/countries.json из data/raw/
```

## Данные

`data/countries.json` — 200 стран и территорий плюс Россия как страна паспорта.
Для каждой: `iso2`, `name_ru`, `hub {city, iata, lat, lon}`,
`visa {regime, days, source_url, verified_at, note}`.

- Режимы собраны веб-поиском 14.11.2026. Основной источник — сводный перечень
  Консульского департамента МИД РФ (kdmid.ru, по состоянию на 13.11.2026) и его
  страницы по странам; местами — официальные порталы самих стран.
- `verified_at: null` — режим не удалось подтвердить официальным источником или
  источники расходятся. В таких случаях записан более строгий вариант, а в
  карточке страны показывается предупреждение.
- Обязательное электронное разрешение до поездки (ETA, K-ETA и т. п.) считается `evisa`.
- Координаты хабов взяты из открытой базы [OurAirports](https://ourairports.com/data/) по IATA-коду.
- Сырые результаты исследования лежат в `data/raw/`, ручные правки — в `scripts/build-data.ts`.

Визовые правила меняются. Перед покупкой билетов проверяйте режим по ссылке из карточки.

## Алгоритм

`src/geo` — haversine, азимут, точка на дуге большого круга.
`src/engine` — чистые функции:

1. Центр окружности C — на дуге current→target в `k·R` от текущей страны (не дальше самой цели).
2. Кандидаты — хабы в радиусе R от C, прошедшие фильтры, не посещённые и не тупиковые.
3. Вес кандидата — `exp(β · (d(current,target) − d(cand,target)) / R)`.
4. Если кандидатов меньше трёх, радиус растёт ×1.25 вплоть до `R_max`.
5. Выбор — взвешенный случайный, ГПСЧ mulberry32 от сохранённого seed и номера вращения.

Достижимость: граф шагов при `R_max`. Тупик — страна, из которой цель недостижима
по ещё не посещённым странам (обратный BFS от цели). Критический радиус —
бинарный поиск по R + BFS; узкое место — перелёт пути, который первым исчезает при уменьшении R.

Допущения:

- Целевая страна считается доступной независимо от визовых фильтров.
- Без авторасширения потолком шага служит сам R, и тупики считаются по нему.
- При расширении центр окружности сдвигается вместе с радиусом, поэтому перелёт
  может быть длиннее R (до `R·(1+k)`).
